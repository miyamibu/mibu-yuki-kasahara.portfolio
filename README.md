ローカル用ポートフォリオ Web（米株/日本株）

概要
- 外部通信なしのフロントエンドのみ（HTML/CSS/JS）。
- 米国株: 株価はUSD表示、評価額はUSD/JPYで円換算。
- 日本株: 株価・評価額ともに円表示。
- データはブラウザのLocalStorageに保存。JSONでインポート/エクスポート可能。
 - 自動取得（任意）: Stooqで株価、exchangerate.hostでUSD/JPYを取得可能。

使い方
1) `index.html` をブラウザで開く（ダブルクリックでOK）。
2) 上部「設定」
   - 手動: USD/JPY を入力して「為替を保存」。価格も手入力。
   - 自動: 「起動時に自動取得」をオンにし、「今すぐ更新」で株価/為替を取得。
3) 「保有銘柄」→ 市場/ティッカー/株数/価格を入力し「追加」。
4) テーブル上の株数・価格は直接編集可能（自動保存）。
5) JSONでバックアップ・復元する場合は「エクスポート」「インポート」を使用。

注意事項
- 自動取得は参考値です（Stooqの終値/遅延値の可能性あり）。
- 価格や為替は厳密なリアルタイムではありません。必要に応じて手入力で上書き可。
- データはこのPCのブラウザにのみ保存されます。別PC/別ブラウザには引き継がれません（JSONで移行可能）。

構成
- `index.html` … 画面本体
- `styles.css` … スタイル
- `app.js` … ロジック（保存・計算・描画）
  - 株価: Stooq CSVをfetchして更新
  - 為替: exchangerate.host から USD/JPY をfetch
