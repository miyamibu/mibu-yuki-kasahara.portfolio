# LONG WEEKEND — ふたりの旅行会議

2026年11月21日〜23日を初期日程にした、2人またはグループ向けの旅行合意サイトです。

## 公開版

GitHub Pages上の静的サイトです。入力はブラウザのlocalStorageに保存されます。

- 箱根・金沢・高松／直島の3案
- 各自の重視項目、1〜5点評価、絶対やりたい／拒否条件
- 平均点、意見差、拒否条件を用いた合意判定
- 回答コードによる別端末データの統合
- 合意成立後だけ宿泊・交通リンクを解放
- Web Share API対応

## 合意条件

首位候補について、次をすべて満たす場合だけ予約ゲートを解放します。

1. 全参加者が全候補を採点済み
2. 平均4.0以上
3. 個人スコアの最大差1.15以内
4. 拒否条件なし

## 任意のバックエンド

`server/` はExpress + SQLiteによる共有APIです。公開版は個人情報をサーバーへ置かないため未接続です。

```bash
cd server
npm install
npm start
```

API:

- `POST /api/trips`
- `GET /api/trips/:id`
- `PUT /api/trips/:id`
- `DELETE /api/trips/:id`
- `GET /health`

書き込み・削除には作成時に返る共有トークンが必要です。本番導入時は、HTTPS、レート制限、期限切れ削除、監査ログ、秘密情報管理を追加してください。

## 予約について

サイトは予約を自動確定しません。合意後に外部予約画面を開き、氏名、総額、日付、人数、部屋、キャンセル条件、食事、交通を本人が確認して確定します。
